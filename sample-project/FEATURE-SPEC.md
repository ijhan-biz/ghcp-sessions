# 기능 스펙 카드 — 멤버십 포인트 서비스 (폴백 실습용)

> 본인 기능을 가져오지 못한 경우, 이 스펙을 **"내 기능 스펙 카드"** 로 채택해 2일 과정을 진행하세요.
> 비식별 예시입니다(고객명/계정/secret 없음).

- 기능명: 멤버십 포인트 적립·사용
- 현재 동작:
  - 결제 금액에 대해 등급(basic/silver/gold)별 비율로 포인트를 적립한다(원 단위 내림).
  - 보유 잔액에서 포인트를 사용(차감)한다.
- 원하는 동작(개선/추가):
  - 사용 시 **음수 포인트·잔액 초과를 오류로 막는다.** (← 우선 slice)
  - (선택) 포인트 **만료**(획득 후 N일) 처리를 추가한다.
  - (선택) 1회 사용 한도 / 일일 적립 한도를 둔다.
- 사용자/시스템 영향: 잘못된 차감·음수 방지로 **잔액 무결성** 보장.
- 제외 범위(non-goal): 실제 결제 연동, DB, 외부 API, 환불 정산.
- 민감정보 제거 확인: [x] 고객명/계정/키/운영로그 없음

## Acceptance Criteria (예시 — Day1·S2에서 본인이 다듬기)
| AC | 범주 | 검증 방법 |
| --- | --- | --- |
| basic 1% / gold 5% 적립(내림) | 정상 | `npm test` |
| 적립: 음수 금액 → 오류 | 예외 | `npm test` |
| 사용: 잔액에서 정상 차감 | 정상 | `npm test` |
| 사용: 음수 포인트 → 오류 | 예외 | `npm test` (skip 해제 후) |
| 사용: 잔액 초과 → 오류 | 경계 | `npm test` (skip 해제 후) |
