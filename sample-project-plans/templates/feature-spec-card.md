# 비식별 기능 스펙 카드 (완성 예시 · Day1-S1)

> 완성본이라 예시가 **채워진 상태**입니다. 원본 작성 규칙: 고객명/계정/키/운영 로그 원문 금지(OR-13).

- 기능명: Plans 칸반 보드 엔진
- 현재 동작: 보드/리스트/카드 CRUD, 카드 이동, 라벨·멤버·마감·체크리스트·코멘트·첨부, 검색·통계, 주입형 저장
- 원하는 동작: (완성) — 위 기능이 순수 함수 + 엔진 경계로 모두 구현·테스트됨
- 사용자/시스템 영향: 누가 무엇을 언제까지 하는지와 마감초과를 한눈에 → 팀 진행 관리
- 제외 범위(non-goal): 실제 DB/파일/클라우드 저장, 실시간 협업(WebSocket), 파일 업로드, 인증 서버, UI 프레임워크
- 민감정보 제거 확인: [x] 고객명/계정/키/운영로그 없음 (멤버는 alice·bob 비식별)

[출력] 변경 요약 → 코드 → 테스트 순서로.
