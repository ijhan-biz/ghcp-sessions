# 기능 스펙 카드 — 유명 SNS 트렌드 분석 엔진 (폴백 실습용·대안)

> 본인 기능을 가져오지 못한 경우, 이 스펙을 **"내 기능 스펙 카드"** 로 채택해 2일 과정을 진행하세요.
> (비식별 예시, secret 없음. 실제 SNS API 키 불필요.)

## 무슨 앱인가
유명 SNS(예: 게시물 목록)를 **검색·수집**해서 **지금 뜨는 해시태그/토픽(트렌드)**을 뽑아 주는 앱입니다.
"트렌드"는 감이 아니라 **고정된 점수 규칙**으로 정합니다(정답이 명확 → 테스트 가능).

## 설계 경계 (중요)
- **SNS 검색(수집)은 주입 가능한 `fetch`로 분리**합니다. 실제 네트워크·API 키 대신 **테스트에서는 fake fetcher**를 주입해 로컬에서 **결정론적으로** 검증합니다.
- 분석 로직(해시태그 추출·점수·랭킹)은 **순수 함수**입니다. 파이프라인: **검색(수집) → 해시태그 추출 → 점수·랭킹 → 상위 N**.

## 트렌드 점수 규칙 (고정)
- 태그 점수 = Σ over (그 태그를 포함한 게시물) `(1 + engagement) * recencyWeight`
- `engagement = likes + reposts * 2`  (reposts 2배 가중)
- `recencyWeight` = 최근일수록 1, 오래될수록 **반감기 7일** 감쇠(`0.5 ** (경과일/7)`)
- 한 게시물 안의 중복 태그는 **1회만** 집계, 점수 내림차순(동점이면 언급 수)으로 상위 N 반환.

## 스펙
- 기능명: 유명 SNS 트렌드 분석 엔진
- 현재 동작:
  - 게시물 텍스트에서 **해시태그 추출**(소문자화).
  - 태그별 **점수·랭킹**으로 상위 N 트렌드 반환.
  - 주입된 `fetch`로 게시물 **검색(수집)**, 실패 시 안전 처리.
- 원하는 동작(개선/추가):
  - **최근성 가중(`recencyWeight`)**: 오래된 글의 태그 점수를 반감기 7일로 감쇠. (← 우선 slice, test-first)
  - (선택) 불용 태그(stopword) 제외, 최소 언급 수 필터.
  - (선택) 급상승(전일 대비 증가율) 지표, 소스 다양성 보장.
- 사용자/시스템 영향: 오래된·저품질 태그를 눌러 **지금 뜨는 것**을 정확히 노출.
- 제외 범위(non-goal): **실제 SNS API 키/rate-limit/OAuth·크롤러 운영**(테스트는 fake fetcher로 대체), LLM 요약, DB.
- 민감정보 제거 확인: [x] 고객명/계정/키/운영로그 없음
