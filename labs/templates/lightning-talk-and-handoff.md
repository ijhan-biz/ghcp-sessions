# 경험 공유 — 라이트닝 토크 + PL Handoff (Day2-S7)

## 라이트닝 토크 자료 (전원 작성 · 대표 3명만 각 3분 발표)
1. 문제 한 줄: 내 기능/반복 업무는 무엇이고 왜 골랐나
2. Before/After: 토큰·프롬프트·게이트·Skill 중 가장 효과 본 것 1개
3. 나의 솔루션 30초 시연: Custom Skill/Agent 입력 1개 → 기대 출력 1개

> Day1 발표는 없습니다. D2·S7 대표 3명은 서로 다른 학습 사례(구현·검증·복구)를 기준으로 선정하며, 전원은 이 3장과 PL handoff를 제출합니다.

## 현업 적용 액션 3개
1. 반복 프롬프트 1개를 Skill/prompt 파일로 표준화
2. 로컬 test + policy-check 를 묶은 최소 게이트 1개 (`npm run gate`)
3. PL/리뷰어와 pass/revise/block 기준 30분 합의

## PL Handoff (1페이지)
| 칸 | 내용 |
| --- | --- |
| 만든 것 | Custom Skill/Agent + 로컬 게이트 |
| 적용 후보 | 팀의 어떤 반복 업무에 |
| 기대 효과 | 토큰/시간/품질 1줄 |
| 필요 지원 | 모델/도구/권한 확인 |
| 다음 단계 | D+7 클리닉 점검 |
